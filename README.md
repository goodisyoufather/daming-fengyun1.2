## ✨ 游戏特色

- 🏰 **建国立业** — 创建你的专属国家，招募义军，逐鹿中原
- 🤝 **合纵连横** — 与玩家结盟或对抗，外交军事多维度策略博弈
- 🎡 **娱乐抽奖** — 幸运大转盘，赢取银两、稀有头像框和珍贵道具
- 📜 **历史答题** — 每天三道明朝历史题，答对即得银两，全对额外送抽奖卡
- 🏆 **排行榜竞技** — 全服玩家实力排名实时更新，登顶榜首名垂青史
- 👥 **好友社交** — 邀请好友，多人同服互动，乱世中结交豪杰

## 🚀 技术栈

- **前端**：HTML5 + CSS3 + JavaScript（像素风 Canvas 渲染）
- **后端**：Node.js + Express
- **部署**：Railway
- **实时通信**：WebSocket 多人在线

## 📦 本地运行

```bash
git clone https://github.com/goodisyoufather/daming-fengyun1.2.git
cd daming-fengyun1.2
npm install
npm start
```
